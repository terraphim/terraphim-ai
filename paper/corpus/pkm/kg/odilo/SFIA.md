# SFIA

Skills Framework for the Information Age (SFIA) is a globally recognised framework for describing skills and competencies in IT and digital roles. Version 8 is used in the Odilo DLT project.

synonyms:: SFIA, Skills Framework for the Information Age, SFIA v8, competency framework, skills framework
