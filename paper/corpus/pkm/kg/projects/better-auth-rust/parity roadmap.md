# Parity Roadmap

Five-phase roadmap for better-auth-rust to achieve feature parity with better-auth (TypeScript) and extend into unique Rust-native capabilities.

## Phases

| Phase | Focus | Status |
|-------|-------|--------|
| 1 | PostgreSQL support, core auth foundations | Spec complete |
| 2 | Passkeys/WebAuthn | Spec + sprint breakdown complete |
| 3 | Enterprise SSO (SAML, OIDC) | Spec + sprint breakdown complete |
| 4 | CLI authentication | Spec planned |
| 5 | Framework adapters (Axum, Actix, etc.) | Implementation plan complete |
