# x402 Payments

HTTP 402 payment protocol integration in better-auth-rust for agent-to-agent economic transactions.

## Concept

x402 enables HTTP-based payment flows where agents can negotiate and complete financial transactions as part of their authentication and authorisation flow.

## Integration with Auth

- Payment capability as an agent capability type
- Transaction audit logging
- Organisation-level billing and quotas
- Rate limiting tied to payment tiers
