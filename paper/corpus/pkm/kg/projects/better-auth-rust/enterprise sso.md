# Enterprise SSO

Enterprise single sign-on support in better-auth-rust via SAML and OpenID Connect.

## Parity Phase 3

Enterprise SSO is planned as parity phase 3 in the roadmap:
- SAML 2.0 integration
- OpenID Connect (OIDC) provider support
- Just-in-time user provisioning
- Group/role mapping from IdP claims
- Multi-IdP support per organisation
- IdP-initiated and SP-initiated flows
