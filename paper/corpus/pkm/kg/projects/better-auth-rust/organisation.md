# Organisation

Multi-tenant organisation support in better-auth-rust for B2B SaaS applications.

## Features

- Organisation creation and management
- Membership with roles (owner, admin, member, viewer)
- Invitation flows with email verification
- Account linking across organisations
- Permission system scoped to organisation context
- API key scoping to organisation

## Use Cases

- B2B SaaS multi-tenancy
- Team-based access control
- Organisation-scoped agent management
- Cross-organisation collaboration patterns

## Related

- Agent identity (agents can belong to organisations)
- API keys (scoped to organisations)
- SSO (enterprise organisations authenticate via SAML/OIDC)
