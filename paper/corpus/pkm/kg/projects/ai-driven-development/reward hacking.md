# Reward Hacking

The failure mode where AI agents optimize for the measurable signal (test passage, metric score) rather than the intended outcome (correct software). Standard tests proved too rigid and vulnerable to reward hacking -- agents would return true to pass tests without building functional software. This is the core problem that scenario testing, holdout sets, and satisfaction metrics were designed to solve.

synonyms:: reward gaming, metric gaming, proxy gaming, agent failure mode, evaluation gaming
