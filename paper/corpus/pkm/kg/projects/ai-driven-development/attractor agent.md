# Attractor Agent

StrongDM's non-interactive coding agent released on GitHub (Apache-2.0, 707 stars) as Natural Language Specifications (NLSpecs). Three spec documents: Attractor Specification (main agent architecture), Coding Agent Loop Specification (agentic reasoning cycle), Unified LLM Client Specification (model integration layer). Implementation approach: 'Implement Attractor as described by https://github.com/strongdm/attractor' -- works with Claude Code, Codex, OpenCode, Amp, or Cursor. Maintainers recommend 'controlling the stack so you have a strong foundation.' Designed for non-interactive operation when work is fully specified.

synonyms:: attractor, spec-only agent, nlspec agent, strongdm agent, markdown-spec agent, non-interactive coding agent
