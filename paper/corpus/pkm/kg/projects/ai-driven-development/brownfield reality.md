# Brownfield Reality

The fact that most enterprise software is legacy systems accumulated over years/decades where the system IS the specification. No written spec captures the thousand implicit decisions from patches, hotfixes, and permanent temporary workarounds. You cannot dark-factory through a legacy system -- the path starts with reverse-engineering implicit knowledge into explicit specifications.

synonyms:: legacy migration, brownfield migration, legacy system constraint, institutional code debt, legacy modernization barrier, dark factory prerequisite gap
