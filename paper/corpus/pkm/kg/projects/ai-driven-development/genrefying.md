# Genrefying

Library science term applied to agent context management: restructuring information to optimize future retrieval. As agents build conceptual hierarchies on the filesystem, those hierarchies become unbalanced, redundant, or confusing. Genrefying is the corrective reorganization -- functionally resembles rebalancing and reindexing in data structures, with LLMs operating directly over the filesystem.

synonyms:: context reorganization, information restructuring, index rebalancing, agent context maintenance, filesystem reorganization
