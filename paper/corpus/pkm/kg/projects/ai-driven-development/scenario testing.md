# Scenario Testing

End-to-end user stories stored outside the codebase, functioning as holdout validation sets analogous to ML training evaluation data. Originated by Cem Kaner (2003) as hypothetical stories used to think through complex problems -- narrative-driven, motivating, credible, complex, and easy to evaluate. StrongDM adapted this for AI-generated code: scenarios are flexibly validated by LLMs rather than boolean assertions, measuring satisfaction (trajectory probability) not pass/fail.

synonyms:: scenarios, external scenarios, behavioral scenarios, out-of-codebase testing, external behavioral specs, kaner scenarios, ai-proof testing, agent evaluation, end-to-end user stories
