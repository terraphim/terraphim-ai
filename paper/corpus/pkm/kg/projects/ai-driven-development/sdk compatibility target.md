# SDK Compatibility Target

Architectural principle for building digital twins: 'Use the top popular publicly available reference SDK client libraries as compatibility targets, with the goal always being 100% compatibility.' Rather than reverse-engineering APIs from scratch, DTU clones target the behavior expected by existing SDK clients, ensuring that code tested against twins behaves identically against production services.

synonyms:: sdk compatibility, client library targeting, 100% compatibility target, dtu construction principle, service clone fidelity
