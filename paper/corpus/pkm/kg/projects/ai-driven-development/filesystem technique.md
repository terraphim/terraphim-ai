# Filesystem Technique

Using the filesystem as mutable, inspectable world-state where agents navigate and contour their own context. Three primitives: create directories with meaningful names, create indexes (typically Markdown), write state to disk. As conceptual hierarchies evolve, agents reorganize them -- a process called 'genrefying' in library science: restructuring information to optimize future retrieval. Implications: self-organizing context (agents maintain own knowledge structures), persistent memory (state survives across sessions), inspectable state (humans can audit/modify/reset), composable knowledge (multiple agents share filesystem state).

synonyms:: filesystem as world-state, agent filesystem, mutable world-state, self-organizing context, agent memory substrate, persistent agent state
