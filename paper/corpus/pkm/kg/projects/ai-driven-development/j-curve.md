# J-Curve

The productivity dip that occurs when AI coding tools are bolted onto existing workflows without redesigning those workflows around AI capabilities. Productivity drops before it recovers. The dip happens because the tool changes the workflow, but the workflow has not been redesigned for the tool -- running a new engine on old transmission.

synonyms:: j-curve dip, adoption j-curve, productivity dip, ai adoption dip, workflow disruption dip, ai productivity paradox, metr slowdown effect
