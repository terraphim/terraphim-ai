# Teaching to the Test

The anti-pattern where AI agents optimize for passing tests rather than building correct software, analogous to education's teaching-to-the-test problem. When tests live inside the codebase, AI can intentionally or unintentionally optimize for test passage rather than genuine correctness. Solved by external scenario testing.

synonyms:: test gaming, overfitting to tests, test-suite optimization, goodhart's law in testing, ai test cheating, agent evaluation gaming
