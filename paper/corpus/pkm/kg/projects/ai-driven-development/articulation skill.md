# Articulation Skill

The capability to write specifications detailed enough for an AI agent to implement correctly without human intervention. Requires rigorous systems thinking that most organizations never needed because humans on the other end could fill gaps with judgment, context, and Slack messages. Machines build what you describe -- ambiguity produces software guesses, not customer-centric guesses.

synonyms:: spec articulation, specification authoring, machine-readable requirements writing, ai-ready spec writing
