# Shift Work

Separating interactive work from fully specified work. Interactive mode: the familiar collaborative cycle of 'generate, clarify, generate, approve, correct' (Cursor, Claude Code, Codex). Non-interactive mode: tasks that are already fully specified -- formal specs (RFCs), existing working applications, execution runs that complete end-to-end once intent is defined. Key principle: 'An existing application constitutes an executable specification.' Non-functional complexity (scalability, security, performance) exists outside functional specification and represents the genuine technical challenge.

synonyms:: interactive vs non-interactive, development mode separation, specified work vs exploratory work, work mode classification, agent operation mode
