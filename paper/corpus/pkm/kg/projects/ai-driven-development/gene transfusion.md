# Gene Transfusion

Transferring functional patterns between codebases by directing coding agents toward concrete exemplars as reference points -- drawn from inside or outside the code estate. Five-step process: identify exemplar, extract pattern (structure/invariants/edge cases), synthesize adapted implementation, validate behavioral equivalence, propagate for reuse. Patterns propagate via cross-language application, direct inlining, or library embodiment. Key principle: 'Patterns encode solutions to recurring problems. With a working exemplar and good tests, an agent can reproduce the same behavior in a new context while adapting to local constraints.'

synonyms:: pattern extraction, cross-system pattern transfer, architectural gene transfer, exemplar-driven transfer, agent pattern reuse, codebase pattern mining, cross-codebase learning
