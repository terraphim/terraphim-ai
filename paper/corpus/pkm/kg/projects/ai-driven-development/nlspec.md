# NLSpec

Natural Language Specification -- a structured document written in natural language (typically Markdown) that is precise enough for an AI coding agent to implement without human interaction. StrongDM's Attractor uses three NLSpecs: main agent architecture, coding agent loop, and unified LLM client. The NLSpec IS the durable artefact; implementations are ephemeral and regenerated from specs by any capable agent.

synonyms:: natural language specification, natural language spec, markdown specification, agent specification format, nl-driven development
