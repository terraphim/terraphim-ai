# Specification as Repo

The architectural pattern where a repository contains only specification files (markdown, structured text) rather than implementation code. The implementation is regenerated by AI agents from the specs as needed. The spec is the durable artefact; code is ephemeral. StrongDM's Attractor repo exemplifies this -- three markdown files that any agent can build from.

synonyms:: spec-as-code, specification-only repository, markdown-driven development, spec-first architecture, disposable implementation
