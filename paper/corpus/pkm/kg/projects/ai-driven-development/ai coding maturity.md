# AI Coding Maturity

A five-level framework (Dan Shapiro) describing the progression of human-AI collaboration in software development, from spicy autocomplete (Level 0) through dark factory (Level 5). Each level represents a shift in the human role from implementer to director to evaluator.

synonyms:: five levels of vibe coding, shapiro framework, vibe coding levels, ai coding levels, vibe coding maturity model, ai development maturity, coding automation levels
