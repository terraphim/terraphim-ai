# Executable Specification

An existing working application treated as a complete behavioral specification for reimplementation. Key principle from shift work: 'An existing application constitutes an executable specification.' Combined with formal specs (e.g., RFC 9113 for HTTP/2) plus validation suites (h2spec, nghttp2), constitutes complete intent for non-interactive agent execution. Bridges brownfield reality with dark factory patterns.

synonyms:: behavioral specification, living specification, application-as-spec, legacy-to-spec conversion, reimplementation source
