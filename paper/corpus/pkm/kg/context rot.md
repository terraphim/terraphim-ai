# context rot

The progressive loss of coherence in a long-running agent session as conversation history, prior decisions, and intermediate code states accumulate. Tasks that were tractable at the start become unpredictable mid-session, and recovery often requires starting over. Context rot is a signal that work has not been decomposed correctly: the response is to plan upfront, break work into sub-problems, and develop each in a small isolated context window (often in parallel agents on isolated workspaces).

synonyms:: context decay, agent context degradation, session rot, long-session drift, conversation rot
