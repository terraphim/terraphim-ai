# specification vs plan

A specification captures what the user wants and is independent of the current code state; it stays set. A plan captures how to build the thing given where the code is now; it is state-dependent and frequently thrown away. In agentic engineering, the agent is required to write the plan to a markdown file before executing so the engineer can review it, surface problems early, and use it as a contract to challenge later drift.

synonyms:: spec vs plan, plan vs spec, specification and plan, agent plan first, plan-first agentic workflow
