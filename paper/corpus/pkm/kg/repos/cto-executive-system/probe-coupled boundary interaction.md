# Probe-coupled boundary interaction

An FPF pattern (C.26.1) modelling situations where a measurement or query changes the state of the system being measured, rather than passively reading it. The "probe" (question, API call, metric, boundary check) is coupled to the system and becomes part of its dynamics. Examples: teams optimising for a published metric (Goodhart's Law), seminar questions that redistribute responsibility, readiness reports that become the focus rather than the release itself.

synonyms:: coupled measurement, active probing, measurement as interaction
