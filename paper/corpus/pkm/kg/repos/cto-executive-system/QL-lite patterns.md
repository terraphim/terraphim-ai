# QL-lite patterns

A simplified quantum-like pattern cluster within FPF, activated only after ordinary patterns (measurement, evidence, conceptual bridges, role work, Q-bundle, coarsening) have been applied. QL-lite provides safeguards: name the ordinary owner, identify the specific representation failure, state the weakest permissible inference, and define stopping conditions for modelling. The heavier evidentiary machine for full quantum-like modelling is reserved for cases where mass reuse of the model is expected or responsible decisions depend upon it.

synonyms:: quantum-like lite, simplified quantum-likeness, QL-lite cluster
