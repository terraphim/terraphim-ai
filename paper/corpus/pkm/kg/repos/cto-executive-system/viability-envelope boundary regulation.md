# Viability-envelope boundary regulation

An FPF pattern (C.26.3) for maintaining viable boundaries in systems where measurement, simplification, or context switching actively changes system state. Rather than assuming boundaries are fixed or passively observable, this pattern treats boundary regulation as active work that consumes resources and must be modelled as part of system dynamics. Related to Conway's Law: system architecture and team architecture are entangled-like and cannot be modelled separately then simply composed.

synonyms:: boundary regulation, viability envelope, active boundary maintenance
