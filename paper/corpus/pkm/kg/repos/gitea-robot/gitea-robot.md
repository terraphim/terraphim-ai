# Gitea Robot

Go CLI and MCP server for Gitea issue management with PageRank-based prioritisation. Replaces tea CLI. Provides triage (PageRank scoring), ready (unblocked task discovery), graph (dependency visualisation), and full issue/PR lifecycle. Used by all ADF agents for task tracking.

synonyms:: gitea-robot, gtr, gitea CLI, pagerank triage, issue management, gitea workflow, gtr CLI
