# RLM

Recursive Language Model orchestration for isolated code execution. TerraphimRlm manages sessions, code execution in Firecracker VMs or Docker containers, budget tracking (tokens + time), query loop orchestration, and knowledge graph validation. SessionManager handles VM affinity and snapshots.

synonyms:: RLM, recursive language model, code execution, sandbox, firecracker, docker executor, terraphim_rlm, isolated execution
