# Shared Learning

Cross-agent knowledge sharing system. SharedLearningStore aggregates learnings from all agents with trust levels (L0-L2), BM25-based deduplication, and trust-gated promotion. Learning injector polls shared store, filters by trust level and context relevance. Wiki sync persists learnings to Gitea.

synonyms:: learning, shared learning, cross-agent learning, learning store, learning injection, shared_learning
