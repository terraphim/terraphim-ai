# Aho-Corasick Automata

Multi-pattern string matching using Aho-Corasick algorithm with LeftmostLongest match kind. Used for concept detection in document text, link generation, and paragraph extraction. Built from thesaurus of normalised terms. FST-based autocomplete with fuzzy matching (Levenshtein/Jaro-Winkler).

synonyms:: automata, automaton, aho-corasick, AC automata, pattern matching, text matching, concept detection, terraphim_automata
