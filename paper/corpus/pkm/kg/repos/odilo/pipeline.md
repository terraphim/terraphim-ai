# Odilo DLT Pipeline

Document processing pipeline for Odilo x MTN DLT project. Multi-stage ingestion: ingest, chunk, embed, quality gate, publish to PostgreSQL/pgvector. Uses domain-model.json for data dictionary enforcement. Linear ODITECH team for traceability, GitHub for human dev, Gitea for AI agent work.

synonyms:: odilo, DLT pipeline, document pipeline, odilo-bitbucket, MTN DLT, ingestion pipeline, zestic-ai/odilo
