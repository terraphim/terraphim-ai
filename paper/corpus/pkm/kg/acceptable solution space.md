# acceptable solution space

The set of agent outputs the engineer will actually accept for a given task. A reviewed, agreed plan functions as a constraint that keeps the agent inside this space. The further an agent drifts from a confirmed plan, the more likely the output lands outside the acceptable solution space and requires starting over. Forcing a plan upfront dramatically increases the probability of staying on track.

synonyms:: acceptable output space, agent solution envelope, agent constraint space, acceptable agent solutions
