# Architecture Metamodel

A precise definition of the constructs and rules needed for creating architecture models. In TOGAF 9.1, the Content Metamodel defines core entities (Actor, Application Component, Business Service, Data Entity, Function, Information System Service, Organisation Unit, Platform Service, Role, Technology Component) and their relationships.

Structure:
- Core content: minimum set for traceability across artifacts (not to be altered)
- Extension content: additional depth for specific modelling scenarios

The metamodel enables:
- Formalised definition of enterprise architecture
- Formalised relationships between objects
- EA tool mapping and interoperability
- Consistent artifact generation (catalogs, matrices, diagrams)
