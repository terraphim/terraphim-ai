# agentic engineering memory

Discipline of building organisational memory systems for AI agents, so that lessons learned by one agent compound across the team rather than being lost between sessions. Coined by memco.ai in the *Agentic Engineering Memory: Field Guide* (https://www.memco.ai/field-guide). Core thesis: "Context is rented. Memory is owned." The field guide identifies the **cold-start tax** (every agent session restarts from zero, paying full token cost and repeating mistakes) and proposes an 8-stage **memory lifecycle**: capture, distill+synthesize, scope, provenance, retrieve, apply, validate, retire. Two memory archetypes: **public commons memory** (shared across orgs/community) and **private, permissioned memory** (org-internal with access control). Diagnostic: the **Memory Reliability Lab** -- a 7-minute privacy-preserving rubric across six dimensions.

Relevance: directly aligned with terraphim-agent's session-search and learning-capture, terraphim_persistence, and the gitea-robot PageRank workflow. Provides external vocabulary (cold-start tax, second-run signal, engineering brain) that we can adopt when marketing ADF and Terraphim.

synonyms:: agentic memory, agent memory engineering, organisational agent memory, memco field guide, cold-start tax
