# Terraphim It: Alternative Control

[Read the integration guide and current acceptance scope](vs-code-terraphim-it/README-alternative-control.md) for the Terraphim It VS Code extension, including document persistence, undo/redo, synonym graph export and preview limitations.

The [packaged CLI examples](vs-code-terraphim-it/README.md#use-the-graph-with-terraphim-grep-and-terraphim-agent) show how to search the exported graph with separately installed `terraphim-grep` and save/read back authored decisions with `terraphim-agent`. Both examples specify the tested clients release and link the public walkthroughs.
